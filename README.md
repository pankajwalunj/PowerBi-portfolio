# Power BI Portfolio 📊

A collection of Power BI dashboards built to practice data modeling, DAX, and interactive visualization design across different business domains.

## Projects

| Project | Description | Link |
|---|---|---|
| 🧸 **Toy Store Sales Dashboard** | Sales, revenue, and profit analysis across toy store locations and product categories | [View project](toy-store-sales-dashboard/) |
| ✈️ **Airline Loyalty Program** | Customer loyalty and engagement analysis for an airline rewards program | [View project](airline-loyalty-program/) |

Each project folder contains its own dashboard file (`.pbix`), source data, a screenshot, and a detailed README with insights.

## Tech Stack

- **Power BI Desktop** — data modeling, DAX measures, dashboard design
- **CSV/Excel** — source data
- **Star schema** data modeling across projects

## About Me

Built by Pankaj Walunj as part of a transition into data analytics and BI. Each project here is meant to demonstrate a different piece of the analytics workflow — data modeling, DAX calculations, and dashboard storytelling.
